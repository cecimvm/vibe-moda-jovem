# 🛹 VIBE — Nova Coleção Streetwear

Landing page responsiva desenvolvida para o lançamento da nova coleção *streetwear* da marca **VIBE**, focada no público jovem (16 anos).

---

## 📌 Sobre o Projeto

A marca de moda jovem VIBE identificou que a grande maioria do seu público-alvo acessa o site por smartphones, principalmente nos intervalos das aulas. Por isso, a prioridade máxima do projeto foi oferecer uma experiência de navegação rápida, fluida e totalmente otimizada para telas de celulares.
